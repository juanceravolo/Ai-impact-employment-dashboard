An interactive Power BI dashboard analyzing how AI adoption is reshaping the global workforce, exploring the relationship between regulation, industry, and human-AI collaboration.

## 📊 Overview

This project explores three core questions:
- How does AI adoption evolve over time and across regulatory contexts?
- Which industries and countries are most affected by AI-driven job displacement?
- Is there a measurable relationship between AI adoption, revenue growth, and employment loss?

## 🔍 Key Findings

1. *Regulation redistributes, it doesn't protect.* Strict-regulation countries show higher human-AI collaboration, but job loss remains significant.
2. *Industry outweighs geography.* Variation in job loss between sectors is greater than variation between countries.
3. *Adoption ≠ shared benefit.* AI adoption correlates with revenue growth, but the job-loss curve does not move proportionally.

## 🛠️ Tools & Techniques

- *Power BI Desktop*
- Custom *DAX measures*: AdopcionAI, JobLossMediana, PromConfianza, ColaboracionPromedio, ValorPorEmpleoPerdido
- Multi-page report with cross-filtering and drill-through navigation
- Accessible color palette (AccessibleTidal theme)
